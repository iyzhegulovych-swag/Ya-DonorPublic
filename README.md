# ЯДонор

Мобільний додаток для донорів крові: довідник центрів по всій Україні,
потреба у крові по групах, календар донацій з нагадуваннями й пам'ятка
донора.

Kotlin Multiplatform, інтерфейс спільний для Android та iOS
(Compose Multiplatform).

## Що вміє

- **Центри крові** — 116 центрів у 24 областях, пошук за назвою, містом
  чи адресою, фільтри за компонентами, обране.
- **Потреба у крові** — які групи крові зараз потрібні у конкретному
  центрі, за даними Українського центру трансплант-координації.
- **Календар донацій** — запланувати візит, позначити виконаним,
  побачити, коли можна здавати знову (60 днів для цільної крові).
- **Дні донора** — окремі дні прийому та виїзні акції, зокрема на
  картці конкретного центру. Всесвітній день донора крові (14 червня)
  є в календарі завжди.
- **Нагадування** — сповіщення напередодні запланованого візиту,
  коли мине інтервал після донації та у Всесвітній день донора.
- **Події в календар телефона** — візит або день донора одним дотиком.
- **Пам'ятка донора** — шість статей, працюють без інтернету.

Акаунта немає: профіль, обране й історія лежать на самому пристрої.

## Структура

| Тека | Що всередині |
| --- | --- |
| `shared/` | уся логіка та інтерфейс — спільні для обох платформ |
| `androidApp/` | точка входу для Android |
| `iosApp/` | точка входу для iOS |

Платформенне (сховище, сповіщення, мережа, дзвінки й карти) описане
через `expect`/`actual`: `shared/src/androidMain` та `shared/src/iosMain`.

## Звідки беруться дані

Довідник центрів вшитий у додаток — він майже не змінюється і має
відкриватися без мережі.

Потреба у крові, статті пам'ятки й розклад днів донора лежать в окремому
публічному репозиторії [iyzhegulovych-swag/Ya-Donordatapp](https://github.com/iyzhegulovych-swag/Ya-Donordatapp):
там щодня працює GitHub Actions, який збирає дані з donor.utcc.gov.ua
і публікує `needs.json`, `articles.json` та `donor-days.json`.

Додаток працює за принципом «спочатку показати, потім оновити»: одразу
бере копії, вшиті у збірку, а потім тихо перевіряє, чи немає свіжіших.
Якщо мережі немає — нічого не ламається, просто дані будуть старішими.

Виправити статтю або подивитись, як влаштований збір даних, — у тому ж
репозиторії.

## Запуск

```bash
./gradlew :androidApp:assembleDebug      # Android
./gradlew :androidApp:installDebug       # одразу на підключений телефон
./gradlew :shared:testAndroidHostTest    # тести
./gradlew spotlessApply                  # форматування
```

APK з'явиться в `androidApp/build/outputs/apk/debug/`.

Стиль коду тримає [Spotless](https://github.com/diffplug/spotless) із
ktlint, правила — в `.editorconfig`. `spotlessCheck` перевіряє, нічого
не змінюючи.

iOS: відкрити теку `iosApp` в Xcode і запустити звідти.
